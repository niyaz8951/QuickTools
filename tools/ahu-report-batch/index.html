AHU Batch Report Export

Work through a whole unit list instead of clicking each report

A userscript for the Daikin Applied project tool. It expands the project, ticks each unit in turn, opens its report, sets the format to RTF and saves it, then moves on — running to the end of the list from wherever you tell it to start. It runs inside the session you are already logged into, so your portal password stays between you and Daikin.

This one is not like the other tools here.

Everything else on Thinkneering runs on this page with nothing to install. This is a script you install into your browser, and it only does anything on tools.daikinapplied.eu. You need your own portal account — it does not provide access to anything.

Install

  1. 1 Add a userscript manager Tampermonkey or Violentmonkey, from your browser's extension store. Either one works.
  2. 2 Open the script Use the install button below. The manager recognises a .user.js file and offers to install it.
  3. 3 Check the match line Confirm it reads tools.daikinapplied.eu before you accept. That is the only domain the script runs on.
  4. 4 Log in as usual Open a project and expand the unit grid. A panel appears in the top right of the page.

Using it

Open a project list and start. The script expands the first project itself, so there is nothing to set up beforehand.

  • Start from unit — where to begin. Leave it at 1 for the whole list, or set it higher to pick up after an interrupted run. It always continues to the end.
  • Fan curve and list price — the report sections to include, ticked in the options dialog for every unit.
  • Stop — finishes the unit in progress, then halts. Everything already saved stays saved.

Reports save one per unit to your normal downloads folder. The first time, the browser will ask whether to allow multiple downloads from the site — say yes, or it will save one file and quietly ignore the rest.

Known limits

  • The script drives element IDs on the vendor's page. A portal update can rename them, and the run stops with the ID it could not find. They are all in the SEL block at the top of the file, so a rename is a one-line fix.
  • A unit that fails is logged and skipped rather than stopping the run, so one bad report does not cost you the rest of the list. The count above the buttons shows how many saved and how many failed.
  • Ticking each unit's box is best-effort. The report opens from the report button, not from the selection, so if a tick does not register the log says so and the export carries on regardless.
  • Reports are generated by the portal, one at a time. A long run takes about as long as it would by hand — it just does not need anyone watching it.
